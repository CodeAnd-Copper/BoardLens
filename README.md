BoardLens

Cross-platform hardware detection utility for Windows and macOS.

BoardLens scans your computer and displays useful hardware and system information in a simple graphical interface.

 Features
 Windows hardware detection
 macOS hardware detection
 CPU information
 RAM information
 GPU information
 Storage information
 Operating system information
 Motherboard information
 BIOS / firmware information
 Windows PowerShell runs silently in the background
 Simple Tkinter GUI
 Supported Systems
Operating System	Support
Windows	✅ Supported
macOS	✅ Supported
Linux	🚧 Planned
 Running from Source

Make sure Python is installed, then run:

python main.py

On macOS you can use:

python3 main.py
